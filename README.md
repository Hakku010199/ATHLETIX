# ATHLETIX (React + Vite)
Install and run:
    npm install
    npm run dev
Build: npm run build
Dependencies: react, react-dom, react-router-dom, lucide-react (+ vite, @vitejs/plugin-react).
Product images are generated SVG artwork (src/data.js, `art()`); replace `images` with real photo URLs when ready.
Checkout is a frontend demo; no payments are processed.
